ЧТО ДЕЛАЕТ НАБОР
Два шага без Root и без подписок: (1) запрещает сторонним приложениям держать вейклоки через adb и AppOps, (2) включает системный зашифрованный DNS, который не отвечает трекерам. Ничего не отправляется на чужие сервера, кроме DNS-запросов к выбранному вами провайдеру.

ЧТО В НАБОРЕ
- freeze_wakelocks.sh : Linux, macOS, Termux. Запуск без аргументов только показывает, что изменится.
- freeze_wakelocks.bat и restore_wakelocks.bat : Windows. Применить: freeze_wakelocks.bat apply. Откат: restore_wakelocks.bat.
- skip_packages.txt : пакеты-исключения (мессенджеры, будильники, банки, коды). Заполните ДО применения.
- dns_profile_guide.md : Private DNS для Android и профиль для iOS, AdGuard DNS и NextDNS.
- adguard_dns_ios.mobileconfig : профиль iOS 14 и новее (не подписан).
- Инструкция.txt : этот файл

ПОДГОТОВКА ТЕЛЕФОНА (ANDROID)
1. Настройки -> О телефоне -> 7 раз нажмите «Номер сборки».
2. Настройки -> Для разработчиков -> включите «Отладка по USB».
3. Подключите кабель, на телефоне подтвердите ключ компьютера («Разрешить отладку по USB»).
4. На компьютере нужен adb (платформенные инструменты Android). Проверка: adb devices должен показать устройство со статусом device.
5. Termux на самом телефоне: pkg install android-tools; включите «Беспроводную отладку» (Android 11 и новее), выполните adb pair и adb connect, затем запускайте скрипт.

ПОРЯДОК РАБОТЫ
1. Заполните skip_packages.txt.
2. Запустите скрипт БЕЗ аргументов (проверка): он покажет список пакетов и ничего не изменит.
3. Применить: ./freeze_wakelocks.sh --apply (или freeze_wakelocks.bat apply). Прежние режимы пишутся в wakelock_changes.txt.
4. Две ночи подряд сравните расход в Настройки -> Батарея при выключенном экране.
5. Откат всего: ./freeze_wakelocks.sh --restore (или restore_wakelocks.bat). Одно приложение: ./freeze_wakelocks.sh --restore-pkg имя.пакета (или restore_wakelocks.bat pkg имя.пакета).
6. Private DNS: следуйте dns_profile_guide.md.

ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
- Запрет вейклоков может задержать уведомления и сигналы у части приложений; на некоторых прошивках настройка сбрасывается после перезагрузки или обновления: повторите запуск.
- Системные пакеты не затрагиваются; другие ограничения батареи вашей прошивки работают независимо.
- DNS режет только запросы к известным трекерам и не лечит вейклоки; приложения с зашитым DoH его обходят.
- Цифры в видео («18 %», «15–20 % за ночь», «30 % износа», «150–400 МБ») ориентиры автора, не замеры: источник и период трафика будут уточнены.
- Скрипты автор на живом телефоне не прогонял; синтаксис команд зависит от версии Android. Первый запуск только в режиме проверки.
- Условия и адреса DNS-провайдеров меняются: проверяйте актуальные условия на их сайтах. Бесплатные тарифы имеют лимиты.
