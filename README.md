# Ночной разряд смартфона: запрет вейклоков и Private DNS без Root

Набор файлов к ролику «Анатомия ночного жора: отключаем скрытые фоновые процессы смартфона». Два шага без Root, без абонентской платы и без стороннего VPN: (1) скрипт через adb запрещает сторонним приложениям держать вейклоки, (2) Private DNS режет запросы к известным трекерам.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Комплексный аудит и внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep30-battery-drain-fix && cd ep30-battery-drain-fix && bash freeze_wakelocks.sh
```
Эта команда только **проверяет** и ничего не меняет (режим по умолчанию). Нужны adb в PATH и телефон с включённой отладкой по USB.

## Как это устроено
1. **Вейклок** это механизм, которым приложение не даёт процессору уснуть. Если он держится ночью, глубокий сон Android (Doze Mode) не наступает: телефон греется и расходует заряд при выключенном экране.
2. Скрипт проверяет `adb get-state`, берёт список сторонних пакетов (`pm list packages -3`) и в режиме применения выполняет `adb shell cmd appops set <пакет> WAKE_LOCK ignore`. **Системные пакеты не трогаются.**
3. Прежний режим каждого пакета записывается в `wakelock_changes.txt`: по нему работает откат.
4. Private DNS (Android 9 и новее) и профиль iOS отправляют DNS-запросы выбранному провайдеру, который отвечает пустышкой на домены трекеров.

## Подготовка телефона (Android)
1. Настройки, О телефоне, 7 раз нажмите «Номер сборки».
2. Настройки, Для разработчиков, включите «Отладка по USB».
3. Подключите кабель и подтвердите ключ компьютера на экране.
4. Проверка: `adb devices` показывает устройство со статусом `device`.
5. Termux на самом телефоне: `pkg install android-tools`, включите «Беспроводную отладку» (Android 11 и новее), выполните `adb pair` и `adb connect`, затем запускайте скрипт.

## Порядок работы и безопасный откат
1. Заполните `skip_packages.txt`: мессенджеры, будильники, банки, приложения кодов.
2. Запустите скрипт без аргументов: он покажет список и ничего не изменит.
3. Применить: `./freeze_wakelocks.sh --apply` (Windows: `freeze_wakelocks.bat apply`).
4. Две ночи подряд сравните расход в Настройки, Батарея, при выключенном экране.
5. **Откат всего:** `./freeze_wakelocks.sh --restore` (Windows: `restore_wakelocks.bat`). **Одно приложение:** `./freeze_wakelocks.sh --restore-pkg имя.пакета` (Windows: `restore_wakelocks.bat pkg имя.пакета`).

## Резервная копия (обязательно)
Перед экспериментами сохраните данные телефона по правилу **3-2-1**: три копии, два разных носителя, одна вне дома или на внешнем диске. Не удаляйте ничего, пока копия не проверена.

## Честные ограничения
- Запрет вейклоков может задержать уведомления и сигналы у части приложений; на некоторых прошивках настройка сбрасывается после перезагрузки или обновления: повторите запуск.
- Private DNS режет только запросы к известным трекерам и **не лечит вейклоки**; приложения с зашитым DoH его обходят. DNS-провайдер видит имена доменов ваших запросов.
- Цифры из ролика («18 % за ночь», «15–20 %», «30 % износа», «150–400 МБ телеметрии») ориентиры автора, не замеры; источника и периода трафика нет.
- Скрипты автор на живом телефоне **не запускал**; синтаксис `cmd appops` зависит от версии Android. Логика `.bat` проверена на подставном adb. Первый запуск только в режиме проверки.
- Адреса и условия AdGuard DNS и NextDNS меняются: проверяйте актуальные условия на сайтах провайдеров. Бесплатные тарифы имеют лимиты.
- «Без подписки» значит без абонентской платы за этот набор; вы используете свой телефон и свой компьютер.
